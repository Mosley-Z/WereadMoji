微读墨记 · 怎么用
════════════════

【它是什么】
把微信读书的阅读数据搬到墨水屏上，两个入口：
· 桌面卡片 —— 悬浮在桌面上的一张卡片，抬眼即看
· 微读墨记 App —— 全屏页面，认真看、翻历史、读划线、导出图片
两者共用同一份本地数据。


【首次配置（只做一次）】
设置页分「初始化」「自定义」「实验室」三页，第一次照「初始化」页从上往下做即可
（「实验室」放实验性功能，见文末）。
⚠ 正式版（不带 Beta）没有「实验室」页，设置页只有「初始化」「自定义」两页；
  也没有「选本机角色」这一步，固定按阅读器端使用。
⚠ 若本机角色选的是「手机端」，设置页会**只保留「初始化」「实验室」两页**：
· 「初始化」页只留「本机角色」与「检查更新」；
· 「自定义」整页、以及初始化里的 API Key / 桌面卡片模块对手机端都用不上，自动隐藏。
想看完整设置页，回「初始化」把本机角色切回「阅读器端」重开即可。

1. 安装 APK
   ⚠ 直接覆盖安装（含 App 内的在线更新）不会影响无障碍服务，装完即用；
     只有「先卸载再安装」才需要回来重开一次。

2. 首次启动：选本机角色（Beta 版功能；正式版没有这一步）
   第一次打开会问「这台设备用来做什么」，二选一：
   · 为阅读器安装 —— 正常看阅读统计 + 桌面卡片（默认）
   · 为手机端安装 —— 当遥控面板用：打开 App 直达「遥控台」（整屏翻页键 +
     顶部状态胶囊），不显示阅读统计；设置入口在遥控台右上角的齿轮
   当时没选也不要紧，默认按「阅读器」；以后可在设置「初始化」页顶部的
   「本机角色」随时改（改完重开 App 生效）。此选择只存本机，不上传。
   ⚠ 正式版固定为「阅读器端」，不弹此选择。

3. 填 API Key
   初始化页的输入框。Key 从哪来：
   浏览器打开 weread.qq.com/r/weread-skills
   → 快速配置 → 登录微信读书 → 获取 API Key → 复制
   再回到这里：如果剪贴板里有，点「粘贴」；
   粘完点「测试连接」确认能读到数据，最后「保存并返回」。

4. 开无障碍
   点初始化页的「打开系统无障碍设置」→ 已下载的服务 → 微读墨记 → 打开。
   权限说明：服务仅在翻页分不清页面时、或服务重连时各读取一次桌面的
   控件结构，判断是否给桌面让位；不读取屏幕上的文字内容，
   不存储、不上传任何数据。

5. 打开桌面卡片
   回初始化页勾选「在桌面显示阅读卡片」，并在下面选一个默认形态
   （本周 / 本月 / 本书 / 本记）。


【桌面卡片怎么用】
卡片固定在屏幕上一处空位，只在桌面第 1 页显示。
可点的三块：

· 左上角抬头
  短按 = 四态循环切换（本周 → 本月 → 本书 → 本记）
  长按 = 隐藏菜单（15 秒 / 1 分钟 / 5 分钟 / 取消）

· 右上角「更新于…」
  短按 = 立刻联网刷新（卡片唯一的取数入口）
  设置「刷新绑定」里勾选的形态会一并更新（默认本周 + 本书）

· 底部两个按钮（本记态）
  左下「上一条」／右下「换一条」
  正文按卡片高度自动铺满：没写想法的划线也能显示满一屏行数，
  写了想法的按两段各自的需要量分配（想法至少留 2 行）
  本书态时换这一行：左下「选书」／右下「打开」
  · 「选书」= 列出最近在读的几本 + 「自动（最近在读）」，点一本即切换
  · 「打开」= 跳微信读书阅读页

· 卡片最底一行（可选功能）
  设置「阅读成就提示」开启后，周/月卡片最底下多一行小字：
  距目标还差多少，达成时是恭喜语；默认关闭，关闭时版面与原来完全一样

其余区域不接收触摸，桌面手势照常。

自动隐藏：切到别的应用、离开桌面第 1 页、刚点过桌面图标，
卡片都会自动让位。


【App 怎么用】
顶部一排大标签：阅读 / 设置 / 待办（Beta 版还多一个「实验室」）。
· 「阅读」标签的标题带一个 ▽：点它下拉，在 5 个界面之间切换 ——
  本周 / 本月 / 本书 / 本记 / 足迹。
· 本周、本月页顶部有周期选择器，可以往回翻历史
  （本书、本记没有周期，选择器自动隐藏）。
· 「足迹」页把统计摊开看：阅读画像 / 年度视图 / 累计视图 / 读书排行。
· 阅读页底部「刷新」按钮：强制重新拉一次数据。

本记页（划线回顾 + 我的想法）：
· 打开就是当天那条「每日一签」
· 底部一行四个按钮，从左到右：
  ① 最左那格是筛选，点一下在「全部 / 只看想法」之间切换
     「只看想法」= 只翻我自己写过的那几百条（原文 + 我的话）
     当前档位看格子里写的字：写「想法」并且反白（黑底白字）= 已筛选
  ② 上一条：沿来时的路退回去
  ③ 换一条：抽下一条
  ④ 导出：把当前这条导出成图片
· 正文内容太长时可上下拖动正文看完整（整行步进，不会把一行字切一半；
  抬头、署名与按钮固定不动）
· 按钮上方显示「第 N / 共 M 条」（M 是全库总数，不是本次抽到的条数）
· 导出 = 生成 480 宽、高度随内容的长图（超过一屏不再被裁），
  存到相册 Pictures/微读墨记/，存完弹系统分享面板
· 导出样式在设置页「自定义」页「本记导出图」区调：纸张底纹 × 字号（本记页与导出图）三档 × 署名/落款开关
· 桌面卡片上「本记」正文字号是**另一项**「本记字号（卡片）」，在同一个「桌面卡片」区，
  默认 17 号（= 桌面应用名称的字号），可调 12–24 号；字越大能显示的行数越少
· 带想法的那条，末行会标一个「想法」
· 本地还没有想法时，「只看想法」会明确写「还没有写过想法」，
  点「筛选」切回「全部」就能看划线 —— 它不会拿纯划线来充数
· 新划的线会在同步后出现（同一本书大约每两小时重拉一次）；
  同步没成功时卡片会说明原因，并且 5 分钟内不再自动重试 ——
  想立刻再试一次，点「刷新」或卡片右上角即可


【遥控台（手机端）】
手机端打开 App 直接进入的就是「遥控台」—— 翻页、发按键、看连接，一个地方全包，
底部四格在「翻页 / 按键 / 键盘 / 连接」四页间切换：
· 「翻页」页：整屏两块巨型翻页键（默认左右各半）：点哪半就按哪个方向翻页。
  三种翻法：① 轻点一下翻一页；② 按住不放连续翻（间隔可调）；
  ③ 在键面上滑一段就翻一页，可连着滑连续翻。
· 「按键」页（走蓝牙键盘通道；需先在设置 · 实验室 · 翻页里把「连接方式」选成「蓝牙连接」）：
  上区是环形轮盘：外圈四个方向扇区（↑ ↓ ← →），圆心圆盘是「确认」；
  下区是六个系统键（两列）：退格 / 空格 / 删除 / 跳格 / 行首 / 行尾。
  用途：在墨水屏上做方向导航、翻菜单、确认，或在输入框里改字。
  ⚠「行首 / 行尾」在输入框里是把光标移到行首 / 行尾（不是滚动整页）；
   方向键在列表里是移动焦点（不是滚动页面），能否用取决于墨水屏当时停在哪。
  ⚠ 受蓝牙键盘协议所限，少数系统键（如返回 / 回桌面 / 菜单）没有对应按键，故不提供。
· 「键盘」页（同样走蓝牙键盘通道）：把手机上的文字打到墨水屏 ——
  上方一个多行输入框，下方「发送」「清空」两个大按钮，再下面五个常用键
  （回车 / 退格 / 空格 / 跳格 / 删除）。
  用法：先让墨水屏停在输入框（例如搜索框），再在手机里输入并点「发送」；
  也可勾选「实时同步输入」边打边发（出问题就关掉，改用「发送」）。
  ⚠ 受蓝牙键盘协议所限：只支持英文 / 数字 / 符号（ASCII）；
   中文与 emoji 会被跳过，并在状态行如实计数（不静默丢字、不谎报成功）。
  逐字符发送的节奏可在「⋯更多」里调快（10ms）/ 中（30ms，默认）/ 慢（80ms）。
· 「连接」页（点底部「连接」，或点顶部状态胶囊进入）：里面有系统自检、
  本机蓝牙名、已配对设备、实时连接日志，以及「让本机可被发现」
  「电池优化白名单」两个入口 —— 连不上时照它自查即可。
· 顶部状态胶囊：一眼看出「未启用 / 等待连接 / 已连接 墨水屏」。
  未连接时翻页键与按键页会整体变淡（"按了没用"一眼可见），连上后恢复。
  胶囊右边两个小图标：⇄ = 交换左右方向（点一下即换，重启后仍记得）；
  ⋯ = 更多（切「左右各半 / 上下各半」排布、调长按连翻的快 / 中 / 慢、
  调键盘页逐字符发送的快 / 中 / 慢、开 / 关「用手机音量键翻页」）。
· 右上角齿轮：进入设置页（手机端为「初始化（本机角色 · 检查更新）」+「实验室
  （配对、角色、通道等）」两页）。
· 还没连上时点一下状态胶囊，会直接进连接页。
· 左上角月亮 / 太阳图标：一键切换「深色 / 亮色」。
  深色模式下遥控台与设置页一起转成深色（配色与官网一致），随手机使用环境选择；
  偏好只存本机，重启后记得。阅读器端不受影响，永远是原样。
· 遥控台只服务「手机端」形态；「阅读器端」一切照旧，看不到它。


【翻页遥控（实验 · Beta）】
用途：手机当遥控器 —— 在手机上按音量键，或（可选）晃一晃手机，
墨水屏上的微信读书就翻页（音量上 = 上一页，音量下 = 下一页）。

设置 · 实验室 · 「翻页」页里先选「连接方式」（同一时间只用一条）：
· 热点连接：走手机热点。手机是等待方、墨水屏是连接方。
· 蓝牙连接：手机当「蓝牙键盘」，走蓝牙，**不用连热点**；翻页键由系统直接收到，
  不会误触划线 / 想法页。选中它时，手机原有的热点遥控会自动结束。
选「关闭」（默认）则什么都不建连，与之前完全一样。

同一个「翻页」页最下面还有「本机晃动」：晃手机翻**本机**上的微信读书，
不用热点也不用蓝牙；两个开关可以同时打开，同时打开时会**一起翻两端**（详见后面那一节）。


── 热点连接 ──
怎么开（两端都装本 App）：
1. 墨水屏：设置 · 实验室 · 翻页 → 连接方式选「热点连接」→ 角色选「墨水屏」
2. 手机：  设置 · 实验室 · 翻页 → 连接方式选「热点连接」→ 角色选「手机」
3. 墨水屏先连上手机热点（墨水屏是连接方，手机是等待方）
4. 两端都点「开始遥控」即可使用

注意：
· ⚠ 手机屏幕熄灭 / 锁屏后收不到音量键（见上），使用期间请保持屏幕点亮。
· 「晃动翻页」是**可选的第二种方式**（默认关）：翻页页里勾上「晃动翻页（手机端）」。
  它与音量键**可以同时使用**。灵敏度分「低 / 中 / 高」三档（默认「中」）：
  太容易误触就调低，要甩很用力才响应就调高。
  ⚠ 晃动要求本应用停在最前（切走或退到后台后不生效）。
  ⚠ 手持走路 / 拿起放下时可能误翻页；不想用时把总开关关掉即可彻底停用。
  一次晃动只翻一页（有冷却，连晃不会连翻）。
· 角色选「手机」后，手机上会隐藏桌面卡片相关的界面 —— 该机只当遥控器用。
· 两端都要先到系统无障碍里打开「微读墨记 · 遥控」（和卡片服务是两个开关）。
· 同一时间只能有一个无障碍服务接管音量键：如果手机上装了「开关控制 /
  Switch Access」这类同类服务，要先把它关掉，否则本服务收不到按键。
· 长时间没有任何翻页指令会自动断开（「空闲自动断开」可调，默认 300 秒），
  断开后要重新点「开始遥控」。
· 换了角色后，回系统无障碍设置把对应的服务重新打开一次。


── 蓝牙连接 ──
怎么开（只在「手机」这一端操作）：
1. 设置 · 实验室 · 翻页 → 连接方式选「蓝牙连接」（本机即注册为蓝牙键盘）。
2. 首次要**配对一次**（手动走一遍，App 不能替你自动配对）：
   ① 点页面上的「让本机可被发现」，在系统弹窗点「允许」（让墨水屏能扫到本机）；
   ② 墨水屏：设置 · 蓝牙 →「与新设备配对」，扫描并点手机的蓝牙名；
   ③ 两端确认配对码。
   ⚠ 若本机与这台墨水屏**以前配对过**，请先在两侧「取消配对 / 忘记此设备」，
     再按上面重新配对 —— 旧配对里没有"蓝牙键盘"能力，不重新配对连不上。
3. 配对过之后，打开这个开关，多数情况下墨水屏会自动连回来；
   若一时连不上（状态显示「已断开 / 等待连接」，通知栏也会跟着提示），**恢复只要两步**：
   ① 墨水屏进入「设置 · 已连接的设备」；② 在「之前连接的设备」里点手机的蓝牙名。
   （重连只能由墨水屏一侧发起，手机这边点不动。）
4. 连接成功后，页面上的「上一页 / 下一页」按钮可立即试翻一次。

注意：
· 墨水屏那一端**什么都不用开**，也不影响被手机控制 —— 翻页键由系统直接接收，
  不经墨水屏上的本 App。这一页在墨水屏端只是说明，不开启就没有任何后台行为。
· 手机上「音量键翻页」默认开（遥控台 · ⋯ 更多里可关）：开着时，手机侧面音量键
  也能翻页 —— 但**翻页期间本机音量调不了**；不用时关掉即可恢复调音量。
  ✅ 手机**熄屏后**仍可用音量键翻页（已实测：息屏状态下按音量键，墨水屏照常翻页）。
· 「热点连接」与「蓝牙连接」**二选一**：切到「蓝牙连接」时，
  手机原有的热点遥控会自动结束，避免两条通道打架。
· 打开后，手机通知栏会常驻一条「蓝牙遥控运行中」，用于保持蓝牙键盘注册（息屏也能用）。
  这条通知会跟着连接状态变：显示「已连接 / 等待墨水屏连接 / 已断开」，方便你一眼看出连没连上。
· 需要 Android 9 及以上；个别系统未提供该能力时，页面会直接提示「本机不支持」，
  请改用「热点连接」。


── 本机晃动（翻本机上的微信读书）──
用途：晃一晃手机，就翻**本机**上的微信读书 —— 不用热点、不用蓝牙，也不需要另一台设备。

怎么开：
1. 设置 · 实验室 · 翻页 → 页面最下面「本机晃动」→ 勾上「启用本机晃动翻页」。
2. 到系统无障碍里打开「微读墨记 · 遥控」（和卡片服务是两个开关）。
3. 切到微信读书里，晃一晃手机即可翻页。

方向（默认）：左晃 = 上一页，右晃 = 下一页，上晃 = 上一页，下晃 = 下一页。
    四个动作可**各自单独**选方向 —— 「本机晃动」组里有四个单选（左晃 / 右晃 / 上晃 / 下晃，
    每个二选一：上一页 / 下一页），互不影响。页面上「当前映射」一行会写出实际生效的方向。

翻页方式（二选一，就在「本机晃动」组里选）：
· 点击边缘：晃一下 = 在屏幕上点一下边缘 —— 点左边 = 上一页，点右边 = 下一页。
· 横向滑动：晃一下 = 在屏幕上左右划一下 —— 右→左 = 下一页，左→右 = 上一页。
  两种都已实测可用，按手感挑一个即可；默认「点击边缘」。

⚠ 目前仅支持**竖屏、左右横向翻页**；横屏暂不支持。

注意：
· ⚠ 若设备没有可用的加速度计（部分墨水屏没有），这一组会多显示一句提醒；
  开关仍可勾选，但晃了不会生效 —— 换台带传感器的设备即可用。
· 「晃动翻页（手机端）」翻的是**墨水屏**上的书（要先选连接方式、角色选「手机」）；
  「本机晃动」翻的是**本机**上的书，与连接方式无关。两个开关互不影响，可同时打开。
· 「一起翻页」：两个开关同时打开、且墨水屏已连上时，晃一次手机会**同时翻两端** ——
  手机翻本机的那本，墨水屏跟着翻它那本。
  此时墨水屏一侧也按**手机侧的方向**翻（跟着上面四个单选走）⇒ 一次晃两端**同向**；
  关掉「本机晃动」后，墨水屏恢复它原来的方向口径。
  ⚠ 手机要停在微信读书里（本机的翻页是"点屏幕边缘"实现的，停在别的界面会点到别处）；
  两端是各翻各的，任一端漏一次就会错开，所以只保证"一起翻"，**不保证页码严格对齐**。
  只在一边看、或不想两端错开时，把另一边关掉即可。


【更新】

· 有新版本不会弹窗打断你。App 启动时会顺便查一次（一天最多一次），
  查到了就在设置页的「版本与更新」里显示出来。
· 更新步骤：设置页 → 版本与更新 → 点「检查更新」
  → 查到新版后按钮会变成「下载并安装 0.x.y」，点它
  → 下载完自动打开系统安装界面 → 点「安装」。
· 第一次更新时系统会要你允许本应用「安装未知应用」，
  跟着提示去开一下；允许后回来再点一次即可。
· 更新包下完会校验 sha256，对不上不会安装。
· 装完新版不用重开无障碍服务：覆盖安装不会清掉它，卡片会自己接着显示。
  只有先卸载再重装的情况，才需要回系统设置把它重新打开。
· 设置页「版本与更新」里能看到当前版本号，方便对版本。
· 「更新通道」可选「正式版（稳定）」或「Beta（尝鲜）」：
  正式版更稳；Beta 抢先玩，但含未定型功能、可能不稳定。
  两条通道的版本号不可直接比较（例如正式版 0.9.1 实际比 Beta 1.0.0-beta.1 更新）。
  ⚠ 从 Beta 切回正式版：只有正式版发过更高的版本号才装得上（系统不允许降级安装）；
  否则会提示「无法直接退回」，等正式版下个版本即可。


【省事技巧】
· 卡片数字不更新？点一下右上角「更新于…」——卡片不会自己定时联网。
· 卡片不见了？先看是不是离开了桌面第 1 页；再看无障碍服务是不是被关掉了
  （覆盖安装不会关它，但卸载重装会）。
· 想临时清场（比如要截桌面）？长按抬头 → 隐藏 5 分钟。
· API Key 不确定对不对？点「测试连接」，
  它会告诉你是 Key 无效、还是网络不通。
· 换 API Key 会清掉上一个账号的全部本地数据（统计、书架、本书进度、
  划线、想法）—— 这是有意为之，免得两个账号的数据混在一起。


【已知小瑕疵】
· 桌面卡片正文按卡片高度自动铺满（纯划线能显示满一屏行数；带想法的两段按各自需要量分配，
  想法至少留 2 行）。内容仍超出卡片时末尾显示…，完整内容去 App 里看。
· 「换一条」连点、把当前这一小把（40 条）抽完时，抽下一把会有一次约 0.4 秒的停顿。
· 书名特别长时，作者那行可能被挤掉一部分。
